# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e entrada de dados em Python criando um jogo da Forca. O jogador tentará adivinhar uma palavra oculta antes que suas tentativas acabem.

## 📝 Tarefas

### 🛠️ Preparar a palavra e exibir o progresso

#### Descrição
Crie a estrutura inicial do jogo: selecione uma palavra aleatoriamente de uma lista predefinida e mostre ao jogador quais letras já foram descobertas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir cada letra ainda não descoberta como um sublinhado, por exemplo, `_ _ _ _`.
- Aceitar palpites de letras e revelar no progresso as letras que aparecem na palavra.

### 🛠️ Controlar as tentativas e encerrar o jogo

#### Descrição
Conduza as rodadas do jogo até que o jogador descubra a palavra ou esgote o número de tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Rastrear e exibir quantas tentativas incorretas ainda restam.
- Encerrar o jogo quando a palavra for adivinhada ou quando não restarem tentativas.
- Exibir uma mensagem de vitória ou derrota ao final do jogo.
